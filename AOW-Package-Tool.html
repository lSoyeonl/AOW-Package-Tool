AOW Package Tool

Для Age of Wushu / Легенды Кунг-Фу

Перед заменой файла в игре сделайте копию. Инструмент работает локально: файлы никуда не отправляются.

Распаковать

Выберите text.package, затем папку назначения. Будет создана папка text.package.files.

Запаковать

Выберите папку text.package.files после редактирования. Новый файл сохранится под выбранным именем.

Готово к работе.
Нужен Google Chrome или Microsoft Edge. Поддерживаются архивы формата PCK0 (.package).
