AOW Package Tool — распаковка и упаковка text.package

1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте AOW-Package-Tool.html в Google Chrome или Microsoft Edge.
3. Нажмите «Выбрать .package и распаковать».
4. Выберите text.package, а затем папку назначения.
5. Изменяйте распакованные файлы в Notepad++.
6. Нажмите «Выбрать папку и запаковать» и укажите папку text.package.files.
7. Сохраните новый text.package.

ВАЖНО
- Перед заменой text.package в папке игры создайте резервную копию.
- Не удаляйте aow_manifest.json из распакованной папки: он сохраняет исходные
  имена и служебные данные для правильной обратной упаковки.
- Программа работает локально и не загружает игровые файлы в интернет.
- Firefox не поддерживается: используйте Chrome или Edge.

Совместимость: архивы PCK0 игры Age of Wushu / Легенды Кунг-Фу.
